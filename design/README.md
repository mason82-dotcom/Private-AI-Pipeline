# Private AI Pipeline – Light UI Design

Enthält den eigenständig ausführbaren, rein lokalen UI-Prototyp `prototype/` für die geplante Verwaltungsoberfläche. Die produktive Version v0.2 im Repo wird **nicht** verändert.

**Designrichtung:** hell, kompakt, funktional, professionelle Entwickler-Konsole; Sidebar, Statuskarten, Tabellen, Chat, Wissen, Gedächtnis, Agenten, Modellübersicht, System, Einstellungen.

- Direkt ausprobieren: `prototype/Private-AI-Pipeline-UI-Demo.html` lokal im Browser öffnen.
- Quellcode: `prototype/index.html`, `prototype/styles.css`, `prototype/app.js`.
- Bilder: `prototype/screenshots/desktop.png` und `mobile.png`.
- Tests: `python prototype/tests/test_ui.py` (Playwright + Chromium erforderlich).
- Schnittstellen-/Sicherheitsgrenzen: `prototype/README.md`.

**Nicht enthalten:** Live-Betriebsdaten, Backend-Integration, Zugriff auf private Projekte oder automatische Änderungen am Pi.
